# Knowledge Hub

## Rules for this folder
- Check here before searching the web. Save anything new you research.
- Every fact cites the exact page: full link, title, publisher, date published, date looked at, and a short quote of the line it came from. For documents: the file and the page.
- A fact with no source is "not confirmed".
- One folder per topic, with a main note named after it. Topics can have subfolders.
