# Close Session

Run this when the person says goodbye ("bye", "that's it", "done for today"), or before starting fresh or condensing a long chat.

1. Look back through the chat for anything not saved yet: decisions, new or finished tasks, facts, people, research (with sources), and preferences about how they like to work.
2. Save each one in its proper note, following every rule.
3. Write or add to today's daily note in `Daily/` (named like 2026-09-29): a few lines using only Decided, Done, Open, Learned.
4. Update [[Tasks]]: add new ones (with the date added), remove finished ones.
5. Reply with a short list of what was saved, as links, then ask: "Anything I missed?"
