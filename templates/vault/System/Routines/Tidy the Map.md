# Tidy the Map

1. Run the checker with Python 3: `python3 "<vault folder>/System/Tools/vault_check.py"`. If Python isn't installed, do the checks by reading the main notes and following their links.
2. Fix the housekeeping yourself, as the person agreed to this routine: add missing contents lines, fix broken links, add missing summaries, rename duplicate notes (fixing every link), and turn plain mentions into links.
3. **Sync copies** (like "Home 2.md", made by iCloud or OneDrive): compare each with its original. If it's an exact copy, move it to Archive. If it's different, show the person both and ask which to keep.
4. Anything that changes actual information (a fact, a rule, where something belongs): ask first, or add it to [[To Review]].
5. Run the checker again to confirm it's clean.
6. Update "Last run" in [[Settings]], and list what you changed.
