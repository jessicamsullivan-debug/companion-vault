# Northlight Studio Client Onboarding

**Use when:** a new client signs.

1. Create the client's note in the Clients folder, using the Client note template.
2. Add the key contact to [[People]], and link them from the client note.
3. Send [[Northlight Studio Welcome Email]].
4. Book the first meeting, and add it to [[Tasks]].
5. Update [[Northlight Studio Sales Pipeline]]: move them to "client".
