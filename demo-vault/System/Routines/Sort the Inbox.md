# Sort the Inbox

1. Look in `Inbox/`: the notes in [[Inbox]] and any files in the folder. If it's empty, say nothing and stop.
2. For each item:
   - Work out where each fact belongs. If you're not sure, don't guess: add it to [[To Review]] ("Inbox item X: which business is this for?").
   - File each fact into the right note, with a link, a summary line, and a source (for a file, the file name and the page).
   - Follow every rule: links, contents lists, contradictions, "not confirmed" for anything the person didn't write themselves.
   - Move files into `Attachments/`, and link each one from the note it went into.
   - For long documents (over about 20 pages), file the key facts and a short summary. The original stays in Attachments.
3. Clear the notes section of [[Inbox]].
4. Update "Last run" in [[Settings]].
5. Show a short receipt: "Inbox sorted: 3 items → `[[Note]]`, `[[Note]]`. 1 question added to To Review."
