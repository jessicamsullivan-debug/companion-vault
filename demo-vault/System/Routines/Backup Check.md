# Backup Check

1. Read the backup method in [[Settings]].
2. Check it in the way that suits the method:
   - Time Machine or File History: ask the person to confirm the drive has been plugged in recently, or check the last backup date if you can.
   - Obsidian Sync: ask the person to confirm Sync shows no errors.
   - iCloud Drive or OneDrive: check the vault is inside the cloud folder and that files aren't set to download only when opened.
   - Private GitHub: check the latest save is recent and the repository is still private.
   - Manual copy: remind the person to copy the vault to their drive now.
3. If anything looks wrong, explain it plainly and offer to help fix it.
4. Update "Last run" in [[Settings]].
